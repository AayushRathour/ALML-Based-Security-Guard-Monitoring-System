Quick Start Guide

1

Installation

Create a virtual environment and install dependencies:

python -m venv venv
venv\Scripts\activate # Windows
pip install -r requirements.txt
2

Setup Database

Run migrations and create admin user:

cd backend
python manage.py migrate
python manage.py createsuperuser
3

Start Server

Launch the Django development server:

python manage.py runserver
4

Access Dashboard

Open your browser and navigate to:

http://127.0.0.1:8000

Troubleshooting

Webcam not detected

Ensure your webcam is properly connected and not being used by another application. Check camera permissions in your OS settings.

Slow detection performance

For CPU-only systems, use YOLOv8n (nano) model. Consider installing CUDA for GPU acceleration or reducing the confidence threshold.

Model download errors

YOLOv8 models auto-download on first use. Ensure you have internet connectivity. Models are cached in ml/model_weights/

Video stream not showing

Click "Start" button first to begin detection. Check that the detection process is running without errors in the terminal.

Configuration

Environment Variables

Create a .env file in the project root:

SECRET_KEY=your-secret-key
DEBUG=True
CONFIDENCE_THRESHOLD=0.4
ALERT_SOUND_ENABLED=True

CUDA Setup (Optional)

For GPU acceleration, install CUDA-enabled PyTorch:

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Frequently Asked Questions

What cameras are supported?

Any USB webcam or built-in laptop camera supported by OpenCV. IP cameras can be configured by modifying the video source in ml/yolo_detect.py.

Can I detect objects other than people?

Yes! YOLOv8 supports 80 COCO classes by default. Modify the detection filter in the code or train a custom model for specific objects.

How do I improve detection accuracy?

1) Use a larger model (yolov8m/l), 2) Train on custom dataset specific to your environment, 3) Adjust confidence threshold, 4) Ensure good lighting conditions.

Is this suitable for production use?

This is a development/prototype system. For production, add: authentication hardening, HTTPS, database backups, Celery for background tasks, proper logging, and monitoring.
